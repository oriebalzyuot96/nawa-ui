# @nawa-ui/core

**Nawa UI for any framework** — an accessible, themeable UI component library. WCAG 2.2 AA, 18 themes (light, dark, high contrast × 6 accents), skeleton loaders and full RTL support. Same components and API in React, Vue, Svelte, Astro and React Native.

- 📖 Docs and live preview: https://oriieebgsmile96.github.io/nawa-ui/
- 🧩 Components: https://oriieebgsmile96.github.io/nawa-ui/components/
- 🎨 Themes: https://oriieebgsmile96.github.io/nawa-ui/themes/

## Install

```bash
npm i @nawa-ui/core
```

## Usage

```js
import '@nawa-ui/core/style.css';
import { applyTheme } from '@nawa-ui/core/theme';
applyTheme({ mode: 'dark', accent: 'indigo' });
```

## Why Nawa UI

- Accessible by default: verified contrast for every theme, focus traps, keyboard patterns, screen-reader labels, reduced motion.
- 18 themes and 3 shapes with one attribute; follows the OS dark mode and high-contrast settings.
- Skeletons, DataTable, Dialog, Drawer, Tabs, Toast, Tooltip, Stepper, Timeline and more.
- One design system across five frameworks.
